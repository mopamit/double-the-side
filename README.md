# מה קורה כשמכפילים את הצלע? – פריזמה

יישומון 8 בסדרת המרובעים לכיתה ז (חלק 4: קשר לאלגברה). גרסה לשער מפגש.

מהלך: ניבוי → גילוי (הכפלת הצלע) → חקר (גרירת x וטבלת ערכים) → השוואה בין (2x)² ל־2x².

## מבנה
```
index.html     היישומון (HTML + CSS + JS בקובץ אחד)
fonts/         Simpler Pro (Light, Regular, Semibold, Bold)
brand/         לוגו Prismind
```

כל הנכסים נמצאים במאגר עצמו; אין תלות ב־Google Drive או בשרת חיצוני.

## פרסום ב־GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / `root`.
