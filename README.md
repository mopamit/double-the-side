# מה קורה כשמכפילים את הצלע? – פריזמה

יישומון 8 בסדרת המרובעים לכיתה ז. גרסה לשער עצמאות.

התלמיד עושה בעצמו, והיישומון רק בודק:
1. בוחר אורך צלע ובונה ריבוע על רשת משבצות.
2. מודד וממלא בטבלה: אורך צלע, היקף, שטח.
3. מסמן צלע באורך פי 2.
4. בונה ממנה ריבוע חדש.
5. מודד את הריבוע החדש, משכפל את הריבוע המקורי ומרצף בעותקים את הריבוע החדש, וממלא בטבלה פי כמה גדלו ההיקף והשטח.
6. "צלע אחרת" מוסיפה שורה לטבלה. אחרי שלוש שורות מופיעה שאלה לכתיבה: האם זה יקרה בכל ריבוע? הסבירו בעזרת הריצוף.

שתי רמות: צלעות שלמות, או גם חצאי משבצת.
